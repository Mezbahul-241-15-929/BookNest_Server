# 📚 BookNest - Server

BookNest Server is the backend API service that powers the BookNest platform. It manages authentication validation, book data storage, user-specific collections, and CRUD operations using MongoDB and Express.js.

Fully Responsive for Mobile, Tablet & Desktop

🌐 Live Site: https://booknest-be304.web.app/

## 📖 Project Description

The BookNest backend provides RESTful APIs for managing books and user collections. It handles database operations, secure data access, and communication between the React frontend and MongoDB database.

The server is designed with scalability, simplicity, and maintainability in mind.

---

## ✨ Features

### 📚 Book Management APIs
- Get All Books
- Get Single Book Details
- Add New Book
- Update Book Information
- Delete Book
- Filter Books by Category

### 👤 User-Based Features
- Store User Added Books
- Retrieve User Specific Books
- Manage Personal Collections

### 🔒 Security
- Firebase Token Verification (Optional)
- Environment Variable Protection
- Secure MongoDB Connection
- CORS Configuration

### ⚡ Database Operations
- Create
- Read
- Update
- Delete (CRUD)

### 🌐 REST API Architecture
- Clean Route Structure
- JSON Responses
- Error Handling Middleware
